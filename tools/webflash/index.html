Orbiversum firmware

Flash the Guition JC3636K718C (ESP32-S3) over USB straight from the browser. No toolchain needed.

This browser has no Web Serial. Use Chrome or Edge on a desktop. Web Serial needs https or localhost.

Image: firmware/orbiversum.bin, version ….

If the board is not detected, hold BOOT while plugging in USB. Flashing replaces the whole flash contents from address 0, including saved settings. Install button: esp-web-tools 10.4.0.
