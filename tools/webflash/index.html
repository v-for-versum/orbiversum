Update — rewrites only the app. The bootloader and the partition table are not touched, so a dropped cable cannot take away what the board boots from. Use this for every routine update.

This browser has no Web Serial. Use Chrome or Edge on a desktop. Web Serial needs https or localhost.

Install — writes everything from address 0, including the bootloader. Only for a fresh board, a board that does not start, or when the release notes say the partition layout changed.

This browser has no Web Serial. Web Serial needs https or localhost.

KirpisDonis recovery

The board cannot be bricked by flashing: the ESP32-S3 download mode lives in ROM. If a write was interrupted and the board is silent or reboots in a loop:

  1. Unplug USB. Hold the BOOT button.
  2. Plug USB in while holding BOOT, then release it.
  3. Press Install above and pick the new serial port.

Do not close this tab and do not touch the cable while the dialog shows progress.

Flashing is done by esp-web-tools 10.4.0. The “Install” button replaces the whole flash contents, including saved settings.
