# Зоны тапа и значки по краям — дизайн

Продолжает `2026-11-13-menu-and-scene-design.md`. Заменяет текстовые подсказки (`^ tap: amp +`, `knob: hz`, `< back`, `ok >`) значками.

## Зачем
Экран 360×360, круглый. Шрифт 6×10 для подсказок мелкий, подписи упираются в край круга, их позиции подбирались руками. Нужен один способ описать «здесь тап делает вот это» и нарисовать это значком, который гарантированно помещается в круг.

## Цели
- Одно описание зоны: область тапа, сторона экрана, значок. И hit-test, и отрисовка берутся из него — разъехаться не могут.
- Значки без текста: `+`, `−`, `<`, `>`, ручка (дуга со стрелкой).
- Позиция значка считается из радиуса круга (R=180) и размера значка, а не подбирается.
- Перевести на зоны `ParamUi` (тап top/bottom), `SceneUi` (подсказки) и меню (назад/вход).

## Не цели
- Тексты строк меню, `hz`/`amp` остаются текстом (это данные, не подсказки).
- Новые жесты, мультитач, анимация значков.
- Общий «визуальный фреймворк».

## Дизайн
Модуль `sdk/os/src/zones.rs` (экспорт из `lib.rs`):
- `Edge { Top, Bottom, Left, Right }`.
- `Glyph { Plus, Minus, Back, Forward, Knob }` — рисуются примитивами embedded-graphics (линии, треугольники, дуга), без шрифтов; размер 16×16 (константа).
- `TapZone { area: Rectangle, edge: Edge, glyph: Glyph }`:
  - `hit(x, y) -> bool`;
  - `glyph_rect() -> Rectangle` — квадрат значка у своей стороны: центр на расстоянии `r` от центра экрана по оси стороны, где `r` = наибольшее значение, при котором угол квадрата остаётся внутри круга с запасом 6 px (`hypot(r, h) ≤ 180 − 6`);
  - `paint(d)` — стирает `glyph_rect` и рисует значок приглушённым цветом.
- Зоны-константы рядом с владельцем: `ParamUi::ZONES` (Top = `Plus`, y<180; Bottom = `Minus`, y≥180), `menu` (Left = `Back`, x<120; Right = `Forward`, x≥120). `ParamUi::input` и `Menu::handle` идут по зонам, а не по магическим числам (`y < 180`, `BACK_X`).
- `SceneUi`: рисует значки зон `ParamUi` + `Knob` у строки `hz`. Строки `TOP_ROW/BOTTOM_ROW/KNOB_ROW/HINT_ROW` и `paint_hints` с текстом удаляются.
- Меню: `BACK_LABEL`/`OK_LABEL` заменяются значками зон; на корне значок `Back` не рисуется (назад некуда).

## Мои решения (поправьте, если не так)
- Подсказка про долгое нажатие («press long to exit») убирается без замены: значок для неё придумать нечем, меню открывается удержанием — это знание жеста, не экрана. Если нужен значок (кольцо с точкой) — добавить `Glyph::Hold`.
- Значок `Knob` — рисуется рядом со строкой значений, не у края: ручка относится к `hz`.
- Размер значка 16 px, цвет приглушённый (как был у подсказок), чтобы не спорить с анимацией.

## Подходы
1. Зоны + значки в `sdk/os` (выбрано): общий тип, переиспользуют ParamUi, сцена и меню (`hal` уже зависит от `orbiversum-os`).
2. Только значки, зоны остаются числами в каждом месте — меньше кода, но подсказка и реальная зона снова могут разойтись.
3. Растровые значки (PNG/битмапы) — красивее, но ассеты, память и тот же вопрос с позициями.

## Тесты
- `glyph_rect` для всех сторон: все 4 угла внутри круга R=180.
- `hit` для границ (y=179/180, x=119/120).
- Значок рисует хотя бы один пиксель в `glyph_rect` и ни одного вне его.
- Существующие тесты ParamUi / Menu / Scene проходят без изменения смысла.

## Остаётся исполнителю
Форма значков в пикселях, точные цвета, имена констант.
